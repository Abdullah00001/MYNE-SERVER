=== BURBERRY ===

--- BRAND NOTE ---
"BURBERRY" embossed on interior
TB monogram = Thomas Burberry initials, primary hardware identifier
House Check = most iconic Burberry pattern
Camel = most iconic Burberry color (matches trench coat heritage)

--- MATERIALS (identify first) ---
House Check: Tan/camel + black + red + white tartan pattern ← SIGNATURE
  → very recognizable plaid/tartan
  → always same colorway
  → coated canvas version most common

Haymarket Check: Smaller version of House Check
  → same colors but tighter/smaller repeat
  → slightly more subtle than House Check

Smooth Leather: Polished calfskin
  → solid colors, no pattern
  → most common on Lola

Quilted Leather: Diamond quilt pattern
  → used on Lola specifically

TB Monogram Canvas: TB initials pattern on canvas
  → modern Burberry branding
  → various colorways

--- MODELS ---
Lola (Mini/Small/Medium):
SHAPE: Structured flap, clean rectangle
QUILT: Diamond quilted leather ← #1 identifier
CLOSURE: TB MONOGRAM CLASP ← #2 identifier
  → TB letters interlocked forming clasp hardware
  → very prominent, centered on flap
STRAP: Chain strap
MATERIAL: Quilted leather most common
CONFUSED WITH Chanel Classic: Lola has TB clasp + Burberry quilting
  Classic has CC turn-lock + Chanel diamond quilt
CONFUSED WITH YSL Loulou: Lola has TB clasp. Loulou has YSL push-lock.
SIZES: Mini=19cm | Small=23cm | Medium=27cm

Pocket Bag (Mini/Small/Medium/Large):
SHAPE: Structured tote
EXTERIOR: VISIBLE EXTERIOR POCKET on front ← #1 identifier
  → large pocket on front face of bag
HANDLES: Top handles + shoulder strap
MATERIAL: House Check or smooth leather
LINING: Check lining visible at top opening
NOTE: Exterior pocket is primary identifier

Olympia (Mini/Small/Medium):
SHAPE: CRESCENT/HALF-MOON shape ← #1 identifier
  → curved bottom, wider in middle
  → soft structured
CLOSURE: Minimal, understated
STRAP: Chain strap
MATERIAL: Smooth leather most common
CONFUSED WITH LV Loop: Both crescent but
  Olympia has Burberry hardware + leather
  LV Loop has LV canvas/Empreinte

Knight:
SHAPE: Structured flap
CLOSURE: KNIGHT/SHIELD HARDWARE ← #1 identifier
  → shield-shaped clasp, heraldic aesthetic
STRAP: Chain or leather
NOTE: Shield hardware immediately identifiable

--- HARDWARE ---
TB Clasp: Interlocked T and B letters
  → Lola exclusive
  → most recognizable Burberry hardware

Shield/Knight hardware: Shield shape
  → Knight bag exclusive

HARDWARE COLORS:
Gold/Brass: Most common ← signature Burberry
Silver: Available but less common

--- CHECK PATTERN IDENTIFICATION ---
House Check:
  → Large plaid squares
  → Colors: Camel/tan + black + red + white
  → Always same colorway
  → Coated canvas = structured/stiff
  → Fabric version = softer

Haymarket Check:
  → Smaller tighter repeat
  → Same colors as House Check
  → More subtle look

TB Monogram:
  → TB initials repeat pattern
  → Various colorways (not just tan)
  → More modern than Check patterns

PHOTO TIP:
House Check vs Haymarket: House Check squares visibly larger
TB Monogram: Letters visible, not plaid squares

--- COLORS ---
Camel: SIGNATURE Burberry warm tan ← most iconic
  → matches iconic Burberry trench coat color
  → warm golden beige, unmistakably Burberry

Warm Sand: Slightly lighter than Camel
  → more beige, less golden than Camel

Dark Brown: Deep chocolate
  → used as trim on Check bags

Black: Pure black
White: Pure white
Burgundy: Deep wine red
Red: True vivid red
Dusty Rose: Muted pink
Baby Pink: Pale light pink
Navy: Deep navy
Pale Blue: Soft cool blue
Forest: Deep rich green
Sage: Soft grey-green
Tan: Medium warm tan

HOUSE CHECK COLOR NOTE:
Check pattern always has camel/tan dominant background
  → trim leather color described separately
  → e.g. "House Check canvas with camel leather trim"
  → e.g. "House Check canvas with dark brown leather trim"

COLOR CONFUSION:
Camel vs Warm Sand: Camel is deeper/more golden.
  Warm Sand is lighter/more pale beige.
Camel vs Tan: Camel is warmer/more golden. Tan is more neutral.
Burgundy vs Dark Brown: Burgundy shows red-purple in light.
  Dark Brown is pure brown, no red.
Navy vs Black: Navy shows blue in light. Black flat.

--- CONDITION (photo indicators) ---
House Check canvas: Check corners for peeling/cracking
  → coated canvas separates at corners with heavy use
  → canvas can crack in cold weather
Quilted leather (Lola): Check diamond pattern for flattening
TB clasp: Check plating on interlocked TB letters
  → gold wears on raised contact points first
Smooth leather: Scratches visible as lighter marks
Lining: Check/tartan lining visible at top opening
  → staining on lining visible in open photos
Chain strap: Check for darkening/plating loss
Base: Check base corners for scuffing
  → canvas bags show scuffing at base corners quickly
Handles: Vachetta-style handles (if present) develop patina
  → similar to LV vachetta darkening with use
